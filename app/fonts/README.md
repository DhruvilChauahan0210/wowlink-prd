# Fonts

Self-hosted so the site never depends on reaching Google Fonts at build time or for visitors.
Each file is the subset WowLink uses, taken from Google Fonts. All seven families are licensed under the
SIL Open Font License 1.1; each licence is alongside as `OFL-<family>.txt`.

| File | Family | Used for |
|---|---|---|
| `fraunces.woff2`, `fraunces-italic.woff2` | Fraunces (variable: wght, opsz, SOFT; Latin) | headings |
| `figtree.woff2` | Figtree (variable wght; Latin) | body text |
| `caveat.woff2` | Caveat (variable wght; Latin) | handwritten notes and labels |
| `noto-serif-gujarati.woff2` | Noto Serif Gujarati (500; Gujarati) | Gujarati words such as આમંત્રણ |
| `farsan-gujarati.woff2` | Farsan (400; Gujarati letters only) | Gujarati in handwritten places (labels, notes, names on personal invitations), where Caveat has no Gujarati |
| `noto-serif-devanagari.woff2` | Noto Serif Devanagari (500; Devanagari) | Hindi headings and text |
| `kalam-devanagari.woff2` | Kalam (700; Devanagari letters only) | Hindi in handwritten places, where Caveat has no Devanagari |
